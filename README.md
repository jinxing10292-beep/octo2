# Octo AI

한국어 대화와 출처 기반 검색을 실험하는 GitHub Pages용 정적 프로토타입입니다. 외부 패키지나 모델 파일을 내려받지 않고 실행할 수 있습니다.

## 실행 및 배포

저장소 루트의 `index.html`을 브라우저에서 열거나 GitHub 저장소의 **Settings → Pages**에서 배포 소스로 `main` 브랜치의 루트(`/`)를 선택하세요. 빌드 과정이나 패키지 설치는 필요하지 않습니다.

## 현재 기능

- 한국어 채팅 화면과 저장된 자료 검색
- 답변 근거가 된 자료 제목 표시 및 근거가 없을 때 답변 유보
- 검색 자료를 직접 추가·삭제하고 선택적으로 출처 링크 등록
- 훈련 데이터 탭에서 대화 예시를 브라우저 로컬 저장소에 저장·삭제
- 대화 예시 JSON 가져오기와 내보내기
- WebGPU 지원 여부 등 브라우저 기능 안내

## 현재 한계

이 프로토타입은 언어 모델이 아닙니다. 정적 자료에서 관련 문장을 검색해 보여주며, 새 문장을 생성하거나 실제로 모델을 학습하지 않습니다. 훈련 데이터는 해당 브라우저의 로컬 저장소에만 저장됩니다.

실제 0.6B 모델을 학습하고 실행하려면 토크나이저, 모델 구조와 가중치, 학습 데이터, 학습·추론 엔진이 필요합니다. GitHub Pages는 정적 파일 호스팅이므로 모델 파일을 브라우저로 가져오는 전송 과정과 사용자 기기의 메모리·연산 한계를 별도로 고려해야 합니다. 브라우저 기능 확인은 모델 실행이나 학습 가능성을 보장하지 않습니다.
