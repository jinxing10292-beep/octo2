# Octo AI

한국어 대화와 출처 기반 검색을 실험하는 GitHub Pages용 정적 프로토타입입니다. 외부 패키지나 모델 파일을 내려받지 않고 실행할 수 있습니다.

## 실행 및 배포

저장소 루트의 `index.html`을 브라우저에서 열거나 GitHub 저장소의 **Settings → Pages**에서 배포 소스로 `main` 브랜치의 루트(`/`)를 선택하세요. 빌드 과정이나 패키지 설치는 필요하지 않습니다.

## 현재 기능

- 한국어 채팅 화면과 저장된 자료 검색
- 답변 근거가 된 자료 제목 표시 및 근거가 없을 때 답변 유보
- 검색 자료를 직접 추가·삭제하고 선택적으로 출처 링크 등록
- 훈련 데이터 탭에서 대화 예시를 브라우저 로컬 저장소에 저장·삭제
- 대화 예시 JSON 가져오기와 내보내기
- 한국어 명사·동사 어간·형용사 어간·부사·조사·어미의 분리된 어휘 목록 탐색 및 JSON 내보내기
- 무작위 초기 가중치에서 시작하는 미니 디코더 트랜스포머의 브라우저 훈련, 이어 쓰기 생성, 가중치 JSON 가져오기·복사·다운로드
- WebGPU 지원 여부 등 브라우저 기능 안내

초기 어휘 목록은 직접 구성한 확장용 씨앗 데이터이며, 사전 전체나 검증된 학습 말뭉치가 아닙니다. 명사·동사 어간·형용사 어간·부사는 중복을 제거한 뒤 각각 최대 500개까지 표시합니다. 조사는 실제 항목만 수록하며, 어미는 종결·연결·전성·선어말 어미로 나눕니다. 용언 어간의 하이픈은 어미를 붙이는 위치를 표시합니다.

## 현재 한계

훈련실에는 무작위 가중치에서 시작하는 실제 미니 디코더 트랜스포머가 있습니다. 1개 층·1개 어텐션 헤드·차원 16·문맥 32자의 문자 단위 다음 문자 예측 모델이며, CPU 역전파로 입력 문장에 대한 가중치를 갱신하고 학습한 가중치로 이어 쓰기를 생성합니다. 대화 예시를 학습 문장으로 불러오거나 텍스트를 직접 제공할 수 있습니다. 이 미니 모델은 검증용으로 작고, 일반적인 대화형 LLM처럼 답하거나 0.6B 모델 수준의 품질을 내지 않습니다. 훈련실에서 학습한 모델은 검색 기반 채팅과도 별도입니다.

가중치는 메모리에만 보관되므로 JSON을 복사하거나 다운로드해서 직접 관리해야 합니다. 가져오는 가중치는 Octo 미니 모델의 구조·문자 어휘와 일치해야 합니다. 어휘가 다른 훈련 문자는 건너뛰며, 모델 가중치는 훈련 문장에 없던 사실이나 지식을 습득했다고 보장하지 않습니다.

실제 0.6B 모델을 학습하고 실행하려면 훨씬 큰 학습 데이터, 토크나이저, 모델 구조와 가중치, 메모리·연산 자원이 필요합니다. GitHub Pages는 정적 파일 호스팅이므로 모델 파일을 브라우저로 가져오는 전송 과정과 사용자 기기의 메모리·연산 한계를 별도로 고려해야 합니다. 브라우저 기능 확인은 큰 모델의 실행이나 학습 가능성을 보장하지 않습니다.
