# Octo AI

한국어 대화와 출처 기반 검색을 실험하는 GitHub Pages용 정적 프로토타입입니다. 외부 패키지나 모델 파일을 내려받지 않고 실행할 수 있습니다.

## 실행 및 배포

저장소 루트의 `index.html`을 브라우저에서 열거나 GitHub 저장소의 **Settings → Pages**에서 배포 소스로 `main` 브랜치의 루트(`/`)를 선택하세요. 빌드 과정이나 패키지 설치는 필요하지 않습니다.

## 현재 기능

- 한국어 채팅 화면과 저장된 자료 검색
- 답변 근거가 된 자료 제목 표시 및 근거가 없을 때 답변 유보
- 검색 자료를 직접 추가·삭제하고 선택적으로 출처 링크 등록
- 훈련 데이터 탭에서 대화 예시를 브라우저 로컬 저장소에 저장·삭제
- 대화 예시 JSON 가져오기와 내보내기
- 한국어 명사·동사 어간·형용사 어간·부사·조사·어미의 분리된 어휘 목록 탐색 및 JSON 내보내기
- 무작위 또는 저장된 가중치에서 시작하는 미니 디코더 트랜스포머의 브라우저 훈련, 이어 쓰기 생성, 가중치 JSON 가져오기·복사·다운로드
- IndexedDB 자동 체크포인트 및 Chrome·Edge에서 사용자가 선택한 로컬 `weights.json`에 훈련 결과 저장
- WebGPU 지원 여부 등 브라우저 기능 안내

기본 가중치는 `weights.json.gz`로 저장해 GitHub의 단일 파일 용량 제한을 피합니다. 브라우저가 내장 gzip 해제 기능으로 불러온 뒤 기존 SHA-256 및 모델 구조 검증을 수행합니다. 훈련 결과를 직접 파일로 저장하려면 훈련 화면에서 별도의 `weights.json`을 연결하면 됩니다. 배포용 가중치를 갱신할 때는 내보낸 JSON을 gzip으로 압축해 `weights.json.gz`를 교체하세요. 원본 `weights.json`은 실수로 다시 커밋되지 않도록 `.gitignore`에 포함됩니다.

초기 어휘 목록은 직접 구성한 확장용 씨앗 데이터이며, 사전 전체나 검증된 학습 말뭉치가 아닙니다. 일상 어휘를 명사·동사 어간·형용사 어간·부사에 각각 최대 300개 추가하되, 기존 어휘와 겹치는 항목은 제외합니다. 중복을 제거한 뒤 범주마다 최대 800개까지 표시합니다. 조사는 실제로 쓰이는 항목만 수록하며, 300개를 억지로 채우지 않습니다. 어미는 종결·연결·전성·선어말 어미로 나눕니다. 용언 어간의 하이픈은 어미를 붙이는 위치를 표시합니다.

## 현재 한계

훈련실에는 무작위 가중치에서 시작하는 실제 미니 디코더 트랜스포머가 있습니다. 5개 층·4개 어텐션 헤드·차원 256·피드포워드 은닉 차원 256·문맥 512토큰·최대 혼합 어휘 5,096개의 다음 토큰 예측 모델이며, CPU 역전파로 입력 문장에 대한 가중치를 갱신하고 학습한 가중치로 이어 쓰기를 생성합니다. 어휘에 등록된 단어는 통째로 하나의 토큰으로 쓰며, 모르는 단어도 문자 조각으로 나누지 않고 사용 가능한 어휘 공간에 전체 단어로 추가합니다. 어휘가 가득 차면 추가하지 못한 단어 수를 알립니다. 새 토큰은 가능한 기존 문자 가중치 평균으로 초기화하고, 모델에 없던 글자는 무작위 초기화합니다. 그러므로 새 토큰은 학습 전에는 학습된 값이 아닙니다. 어미 토큰도 보관하지만 단어를 자동으로 형태소 분해하지는 않습니다. 기존 가중치를 불러오면 문자·어미·기본 단어를 보충해 기본 어휘를 최대 4,072토큰까지 채우고, 이후 학습 문장의 새 단어를 위해 최대 1,024토큰을 남겨 둡니다. 사용자는 이 한도 안에서 보충된 단어를 예문으로 훈련할 수 있습니다. 최대 어휘를 모두 채우면 약 4,713,960개 매개변수입니다. 512토큰 문맥으로 CPU 훈련·생성을 할 때 처리 시간이 길고 브라우저 메모리 사용량이 클 수 있습니다. JSON 가중치는 수십 MB에서 256 MiB에 이를 수 있습니다. 대화 예시를 학습 문장으로 불러오거나 텍스트를 직접 제공할 수 있습니다. 이 미니 모델은 일반적인 대화형 LLM이나 0.6B 모델보다 훨씬 작고, 훈련실 모델은 검색 기반 채팅과도 별도입니다.

가중치는 훈련 중 25단계마다, 완료 또는 중지 시 이 브라우저의 IndexedDB에 체크포인트로 저장되고, 다음 방문 때 불러옵니다. 모델 구조가 바뀔 때마다 체크포인트 키와 가중치 형식을 분리하므로 기존 체크포인트는 삭제하지 않고 자동 불러오기 대상에서 제외합니다. 페이지 시작 시 현재 형식의 체크포인트를 먼저 확인하며, 없으면 배포된 `weights.json.gz`를 브라우저 내장 gzip 해제 기능으로 불러옵니다. 가져온 가중치도 검증 후 체크포인트로 저장됩니다. 로드한 가중치에 빠진 기본 단어 토큰은 학습된 행렬 값은 그대로 보존한 채 문자 가중치 평균으로 초기화해 추가하며, 이 확장 결과를 파일에 반영하려면 앱에서 가중치를 다시 다운로드해야 합니다. Chrome·Edge에서는 `weights.json 연결`을 눌러 사용자가 선택하고 쓰기 권한을 준 로컬 파일에 훈련 완료·중지 결과를 기록할 수 있습니다. 브라우저는 GitHub Pages의 원격 파일을 직접 수정하거나 GitHub에 업로드할 수 없으며, 저장소에 반영하려면 내보낸 JSON을 gzip으로 압축해 `weights.json.gz`로 교체해야 합니다. 연결 파일 권한은 브라우저에 따라 다시 허용해야 할 수 있습니다. 큰 모델 가중치 파일을 위해 가져오기·내보내기 최대 크기는 256 MiB입니다. 다운로드·복사용 파일에는 모델 JSON의 SHA-256 체크섬이 들어가며 가져올 때 이를 다시 계산해 확인합니다. 엄격한 패키지·모델 구조·가중치 차원·유한 숫자 검사를 통과해야 합니다. 복사해 붙여넣거나 파일을 직접 선택해 검증할 수 있습니다. 체크섬은 전송 중 우발적 손상이나 변경을 발견하는 무결성 확인용이지, 파일 작성자를 인증하는 디지털 서명이 아닙니다. 신뢰하는 GitHub Pages 주소(HTTPS)에서 받은 파일만 사용하고, 모델 JSON을 개발자 콘솔이나 스크립트로 실행하지 마세요. 사이트 소스나 GitHub 계정이 침해되면 악성 스크립트가 배포될 수 있으므로 계정의 다중 인증과 저장소 권한도 보호해야 합니다. 가져오는 가중치는 현재 Octo 미니 모델의 구조·혼합 어휘와 일치해야 합니다. 어휘가 다른 훈련 토큰은 건너뛰며, 모델 가중치는 훈련 문장에 없던 사실이나 지식을 습득했다고 보장하지 않습니다.

실제 0.6B 모델을 학습하고 실행하려면 훨씬 큰 학습 데이터, 토크나이저, 모델 구조와 가중치, 메모리·연산 자원이 필요합니다. GitHub Pages는 정적 파일 호스팅이므로 모델 파일을 브라우저로 가져오는 전송 과정과 사용자 기기의 메모리·연산 한계를 별도로 고려해야 합니다. 브라우저 기능 확인은 큰 모델의 실행이나 학습 가능성을 보장하지 않습니다.
